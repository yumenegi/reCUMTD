# Notes

## Suggested Structure

1. Title Page (title, names, date, class)
   - substantive terms first, "report" last.
2. Summary/Abstract (cap at ~100 words)
   - active voice,
   - past-tense for research done
   - present tense for ongoing activities
   - include the recommendations
3. Table of Contents
   - hyperlinked (so no amsart sadge)
4. Introduction
   - directly state purpose
   - explictly state audience
   - note limitations
5. Body
   - I think that we should probably go with IMRAD
6. Conclusion
   - backwards to the report
7. Recommendations (bulleted list)
   - forward to the future
8. References
9. Appendices
   - code details?

## Style

- Use the 3rd person with active voice; the goal is to create distance.
- Avoid: "will", personal pronouns, "it".
